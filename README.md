# FreshMarket - Сайт продажи овощей и фруктов

Современный и красивый сайт для продажи свежих овощей и фруктов, созданный с использованием HTML, CSS и JavaScript без внешних библиотек.

## 🎨 Особенности дизайна

- **Современный минималистичный дизайн** с использованием градиентов и теней
- **Адаптивная верстка** для всех устройств
- **Плавные анимации** и переходы
- **Интерактивные элементы** с hover-эффектами
- **Красивая цветовая схема** в зеленых тонах

## 📱 Функциональность

### Основные разделы:
- **Главная страница** с hero-секцией
- **Каталог продуктов** с фильтрацией по категориям
- **Информация о компании**
- **Контактная форма**
- **Корзина покупок** (базовая функциональность)

### Интерактивные элементы:
- Фильтрация продуктов по категориям (фрукты, овощи, ягоды)
- Добавление товаров в корзину
- Плавная прокрутка по разделам
- Анимации при скролле
- Уведомления о действиях пользователя

## 🚀 Запуск проекта

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в любом современном браузере
3. Наслаждайтесь красивым сайтом!
